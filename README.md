# Πρότυπα · Προετοιμασία

Εφαρμογή προετοιμασίας για τις εξετάσεις εισαγωγής στα Πρότυπα Γυμνάσια, για έναν μαθητή και τους γονείς του. Ακολουθεί τη μορφή εξέτασης 2025–2026: 40 ερωτήσεις πολλαπλής επιλογής, 150′, φύλλο απαντήσεων.

- **Μαθητής**: εφαρμογή Android (APK) ή web.
- **Γονείς**: web (και στο iPhone, «Προσθήκη στην οθόνη Αφετηρίας»). Βλέπουν πρόοδο, θεωρία με οδηγό γονέα, απαντήσεις και διαγωνίσματα, και δίνουν αναθέσεις και σημειώσεις.
- Ο συγχρονισμός γίνεται μέσω **Firebase** (Authentication + Firestore). Η εφαρμογή δουλεύει και χωρίς internet και συγχρονίζει όταν βρει σύνδεση.
- **Κανένα προσωπικό στοιχείο δεν υπάρχει στον κώδικα.** Τα μέλη της οικογένειας (email, ονόματα, ρόλοι) ορίζονται στην πρώτη σύνδεση και αποθηκεύονται μόνο στη βάση Firestore της οικογένειας.

Οδηγοί χρήσης σε PDF: [`docs/`](docs/).

## Εγκατάσταση για τη δική σας οικογένεια

### 1. Firebase
1. [console.firebase.google.com](https://console.firebase.google.com) → **Create project**.
2. **Build → Authentication → Get started → Email/Password → Enable**.
3. **Build → Firestore Database → Create database** (production mode, περιοχή `eur3`).
4. **Firestore → Rules**: επικολλήστε όλο το [`firestore.rules`](firestore.rules) → **Publish**. Οι κανόνες δεν περιέχουν email: μέλος είναι όποιος υπάρχει στη λίστα μελών της βάσης.
5. **Authentication → Users → Add user**: ένας χρήστης (email + κωδικός) για κάθε γονιό και για τον μαθητή.
6. **Project settings → General → Your apps → Web (</>)**: αντιγράψτε το `firebaseConfig`.

### 2. Αντίγραφο του repo
1. **Fork** αυτού του repo (ή «Use this template»).
2. Στο [`app/firebase-config.js`](app/firebase-config.js) βάλτε το δικό σας `firebaseConfig` και στο `remoteBase` τη διεύθυνση του δικού σας GitHub Pages (`https://<όνομα-χρήστη>.github.io/<repo>/`).
   Τα στοιχεία του `firebaseConfig` δεν είναι μυστικά· την ασφάλεια την κάνουν οι κανόνες.
3. **Settings → Pages → Source: GitHub Actions**. Η εφαρμογή ανεβαίνει στο web σε 1–2 λεπτά.
4. Το APK χτίζεται αυτόματα και εμφανίζεται στα **Releases**.

### 3. Πρώτη σύνδεση: «Ρύθμιση οικογένειας»
Ο πρώτος γονιός που συνδέεται βλέπει την οθόνη **Ρύθμιση οικογένειας** και ορίζει: το όνομά του, τον μαθητή (email, όνομα και πτώσεις, π.χ. «του Νικόλα») και προαιρετικά τον δεύτερο γονιό. Από εκεί και πέρα, μέλη προσθέτονται/αλλάζουν από **Ρυθμίσεις → Μέλη οικογένειας**.

### 4. Συσκευές
- **iPhone**: Safari → διεύθυνση της εφαρμογής → Κοινοποίηση → **Προσθήκη στην οθόνη Αφετηρίας**.
- **Android**: `https://github.com/<όνομα-χρήστη>/<repo>/releases/latest/download/protypa.apk` → άνοιγμα → εγκατάσταση. Για ενημέρωση, το ίδιο link· η πρόοδος δεν χάνεται.

## Πώς δουλεύει το πρόγραμμα μελέτης

- Ο μαθητής δουλεύει **ένα κεφάλαιο τη φορά**. Ένα κεφάλαιο «κλείνει» όταν κάνει όλα τα μαθήματα θεωρίας **και** πάρει τουλάχιστον **70%** στο τεστ κεφαλαίου. Τότε ανοίγει αμέσως το επόμενο.
- Οι ημερομηνίες χρησιμεύουν για σύγκριση: η θεωρία πρέπει να τελειώσει Χ εβδομάδες πριν την εξέταση (προεπιλογή 12). Οι γονείς βλέπουν **«Μπροστά / Στον στόχο / Πίσω κατά ~Χ μέρες»** και πρόβλεψη τέλους με τον σημερινό ρυθμό.
- **Σειρά κεφαλαίων**: Ρυθμίσεις → «Σειρά κεφαλαίων» (σήμανση «διδάχθηκε», «Τα διδαγμένα πρώτα», ↑ ↓).
- **Ώρες διαβάσματος**: Ρυθμίσεις → ώρα ανά ημέρα· το κινητό Android του μαθητή βγάζει ειδοποίηση με τη σημερινή εργασία.

## Αρχεία PDF (θέματα, ενδεικτικά, βιβλία)

Τα πρωτότυπα PDF βρίσκονται στον κλάδο **`files`** (όχι στο `main`, για να μένει ελαφρύ) και δημοσιεύονται μαζί με την εφαρμογή στο `<Pages>/files/...`. Ο κατάλογος είναι στο `source/files.json`. Στην εφαρμογή: **Εξάσκηση → 📁 Αρχείο**, **📖 Άνοιγμα** στις παραπομπές βιβλίων, **📄 Πρωτότυπο** κάτω από τη λύση κάθε ερώτησης εξετάσεων/ενδεικτικών.

## Πώς ενημερώνεται το περιεχόμενο χωρίς να χάνεται η πρόοδος

- Η πρόοδος αποθηκεύεται στο Firebase και συνδέεται με το **σταθερό id** κάθε ερώτησης (π.χ. `2026-15`).
- Το περιεχόμενο είναι ξεχωριστό αρχείο (`app/content/content.json`) με αριθμό έκδοσης· η εφαρμογή κατεβάζει μόνη της τη νεότερη έκδοση από το GitHub Pages, χωρίς νέο APK.
- Νέες ερωτήσεις / διορθώσεις: φάκελος `source/` και μετά
  ```
  python3 tools/build_content.py "τι άλλαξε"
  ```
  Κανένα id δεν σβήνεται ποτέ (`tools/id-registry.json`)· για απόσυρση: `"retired": true`.

## Δομή

```
app/            η εφαρμογή (HTML/CSS/JS) που ανεβαίνει στο web και μπαίνει στο APK
  core.js       δεδομένα, Firebase, μέλη, πρόγραμμα μελέτης, πλοήγηση
  student.js    οθόνες μαθητή: θεωρία, εξάσκηση, κείμενα, παιχνίδια, αρχείο
  exam.js       διαγωνίσματα και φύλλο απαντήσεων
  parent.js     οθόνες γονέα, ρυθμίσεις, μέλη
  notify.js     ειδοποιήσεις (Android)
  content/      περιεχόμενο (παράγεται από το source/)
source/         πηγές: ερωτήσεις, κείμενα, θεωρία, λεξιλόγιο, εξέταση, κατάλογος αρχείων
tools/          build_content.py, μητρώο ids
firestore.rules κανόνες ασφαλείας Firebase (χωρίς προσωπικά στοιχεία)
docs/           οδηγοί χρήσης (PDF)
.github/        αυτόματο build: web (Pages) και APK (Releases)
```
