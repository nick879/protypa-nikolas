# Πρότυπα · Προετοιμασία του Νικόλα

Εφαρμογή προετοιμασίας για τις εξετάσεις των Πρότυπων Γυμνασίων. Ακολουθεί τη μορφή εξέτασης 2025–2026: 40 ερωτήσεις πολλαπλής επιλογής, 150′, φύλλο απαντήσεων.

- **Νικόλας**: εφαρμογή Android (APK).
- **Γονείς**: η ίδια εφαρμογή στο web. Στο iPhone μπαίνει στην αρχική οθόνη σαν κανονική εφαρμογή. Βλέπουν πρόοδο, θεωρία με οδηγό γονέα, απαντήσεις και διαγωνίσματα, και δίνουν αναθέσεις και σημειώσεις.
- Ο συγχρονισμός γίνεται μέσω **Firebase** (project `protypa-nikolas`). Η εφαρμογή δουλεύει και χωρίς internet και συγχρονίζει όταν βρει σύνδεση.

## Τι περιέχει

| | |
|---|---|
| Ερωτήσεις | 1033: επίσημα θέματα 2014–2026, ενδεικτικά 2017–2026, νέες ερωτήσεις εξάσκησης |
| Κείμενα | 49 κείμενα με ερωτήσεις Γλώσσας |
| Θεωρία | 14 κεφάλαια (6 Γλώσσας, 8 Μαθηματικών) από τα σχολικά βιβλία, με λυμένα θέματα εξετάσεων και οδηγό γονέα |
| Διαγωνίσματα | Επίσημα 2020–2026, νέα διαγωνίσματα με τη δομή του 2025, μισά διαγωνίσματα (75′) |
| Φύλλο απαντήσεων | Ίδια διάταξη με το επίσημο: κύκλοι, ομάδες Α/Β, 6ψήφιος κωδικός |

## Εγκατάσταση (μία φορά)

### 1. Κανόνες ασφαλείας στο Firebase
1. [console.firebase.google.com](https://console.firebase.google.com) → project **protypa-nikolas** → **Firestore Database** → καρτέλα **Rules**.
2. Σβήστε ό,τι υπάρχει και επικολλήστε όλο το περιεχόμενο του αρχείου [`firestore.rules`](firestore.rules).
3. Πατήστε **Publish**.

Οι κανόνες επιτρέπουν πρόσβαση μόνο στα τρία email της οικογένειας.

### 2. Λογαριασμοί
Στο Firebase → **Authentication** → **Users** → **Add user**. Φτιάξτε έναν χρήστη για κάθε email με τον κωδικό του:
- *** (μπαμπάς)
- *** (μαμά)
- *** (Νικόλας)

Αν ξεχάσει κάποιος τον κωδικό, πατάει «Ξέχασα τον κωδικό» στην οθόνη σύνδεσης.

### 3. Ιστοσελίδα (GitHub Pages)
Στο GitHub: **Settings** → **Pages** → **Build and deployment** → **Source: GitHub Actions**.
Μετά από 1–2 λεπτά η εφαρμογή είναι στο **https://nick879.github.io/protypa-nikolas/**.
(Αν δεν ανέβει αμέσως: **Actions** → «Web (GitHub Pages)» → **Run workflow**.)

### 4. iPhone της μαμάς
1. Ανοίξτε το παραπάνω link στο **Safari**.
2. Πατήστε το κουμπί **Κοινοποίηση** (τετράγωνο με βελάκι) → **Προσθήκη στην οθόνη Αφετηρίας**.
3. Ανοίξτε την από το εικονίδιο «Πρότυπα» και συνδεθείτε.

### 5. Κινητό Android του Νικόλα
1. Στο κινητό ανοίξτε: **https://github.com/nick879/protypa-nikolas/releases/latest/download/protypa.apk**
2. Ανοίξτε το αρχείο που κατέβηκε. Την πρώτη φορά το Android ζητά να επιτρέψετε «εγκατάσταση από άγνωστες πηγές» στον browser. Επιτρέψτε το.
3. Για **ενημέρωση** της εφαρμογής: ξανακατεβάζετε το ίδιο link και το εγκαθιστάτε από πάνω. Δεν χρειάζεται απεγκατάσταση και η πρόοδος δεν χάνεται.

## Πώς δουλεύει το πρόγραμμα μελέτης

- Ο Νικόλας δουλεύει **ένα κεφάλαιο τη φορά**. Ένα κεφάλαιο «κλείνει» όταν κάνει όλα τα μαθήματα θεωρίας **και** πάρει τουλάχιστον **70%** στο τεστ κεφαλαίου. Τότε ανοίγει αμέσως το επόμενο, όποια μέρα κι αν είναι.
- Οι ημερομηνίες χρησιμεύουν μόνο για σύγκριση. Η θεωρία πρέπει να τελειώσει Χ εβδομάδες πριν την εξέταση (προεπιλογή 12). Η εφαρμογή συγκρίνει πόσα βήματα έχει κάνει με όσα θα έπρεπε ως σήμερα και δείχνει στους γονείς **«Μπροστά / Στον στόχο / Πίσω κατά ~Χ μέρες»**, μαζί με πρόβλεψη πότε θα τελειώσει με τον σημερινό ρυθμό.
- Αν αλλάξει η ημερομηνία εξέτασης (Ρυθμίσεις), όλα ξαναϋπολογίζονται.
- **Αλλαγή σειράς:** Ρυθμίσεις → «Σειρά κεφαλαίων». Σημειώστε «το έχει διδαχθεί στο σχολείο», πατήστε «Τα διδαγμένα πρώτα» ή μετακινήστε με ↑ ↓ και μετά «Αποθήκευση σειράς». Κάθε σειρά είναι έγκυρη· βγαίνει μόνο προειδοποίηση αν π.χ. τα Ποσοστά μπουν πριν τα Κλάσματα. Ένα κεφάλαιο που έχει ήδη ξεκινήσει ολοκληρώνεται πρώτα.

## Πώς ενημερώνεται το περιεχόμενο χωρίς να χάνεται η πρόοδος

- Η πρόοδος (απαντήσεις, μαθήματα, διαγωνίσματα) αποθηκεύεται στο Firebase και συνδέεται με το **σταθερό id** κάθε ερώτησης, π.χ. `2026-15`. Δεν αποθηκεύεται μέσα στην εφαρμογή.
- Το περιεχόμενο είναι ξεχωριστό αρχείο (`app/content/content.json`) με αριθμό έκδοσης. Κάθε φορά που ανοίγει, η εφαρμογή ελέγχει αν υπάρχει νεότερη έκδοση στο GitHub Pages και την κατεβάζει. Δεν χρειάζεται νέο APK.
- Νέες ερωτήσεις, νέα κείμενα και διορθώσεις μπαίνουν στον φάκελο `source/`. Μετά τρέχει:
  ```
  python3 tools/build_content.py "τι άλλαξε"
  ```
  Το script ελέγχει ότι κανένα id δεν χάθηκε (`tools/id-registry.json`) και ανεβάζει την έκδοση. Μια ερώτηση δεν σβήνεται ποτέ. Αν πρέπει να βγει από τη χρήση, παίρνει `"retired": true`.
- Η ημερομηνία της εξέτασης βρίσκεται στο `source/exam.json`. Οι γονείς μπορούν να την αλλάξουν και από τις **Ρυθμίσεις**.

## Δομή

```
app/            η εφαρμογή (HTML/CSS/JS) που ανεβαίνει στο web και μπαίνει στο APK
  core.js       δεδομένα, Firebase, πρόγραμμα μελέτης, πλοήγηση
  student.js    οθόνες μαθητή: θεωρία, εξάσκηση, κείμενα, παιχνίδια
  exam.js       διαγωνίσματα και φύλλο απαντήσεων
  parent.js     οθόνες γονέα
  content/      περιεχόμενο (παράγεται από το source/)
source/         πηγές: ερωτήσεις, κείμενα, θεωρία, λεξιλόγιο, εξέταση
tools/          build_content.py, μητρώο ids
firestore.rules κανόνες ασφαλείας Firebase
.github/        αυτόματο build: web (Pages) και APK (Releases)
```
